# 🌙 Sleep Wellness Shorts & Reels AI Agent (100% Free Pipeline)

An autonomous, 100% free AI agent that generates ready-to-upload, high-retention 9:16 vertical short videos for **YouTube Shorts, Instagram Reels, and TikTok** in the **Sleep & Wellness** niche.

---

## ⚡ What This Agent Does:
1. **Sleep Science Script Generator**: Writes high-retention scripts (Hooks, science-backed facts, practical takeaways, and loop outros).
2. **Crystal Clear Voiceover (Edge TTS)**: Uses Microsoft Edge Neural Voice (`en-US-ChristopherNeural` - calm, authoritative sleep expert tone).
3. **B-Roll Visuals**: Fetches authentic vertical B-roll visuals (real cozy bedroom, sleep, night sky, meditation, brain anatomy).
4. **Dynamic Viral Captions**: Generates styled word-by-word animated subtitles with yellow highlight keywords.
5. **Therapeutic Ambient Music**: Blends soothing 432Hz ambient sleep frequencies and delta tones in the background.
6. **FFmpeg 1080x1920 MP4 Video**: Renders 100% watermark-free, high-definition videos saved directly to `output/`.
